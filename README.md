# Экспресс-самодиагностика «Кто управляет вашим временем?»

Статический клиентский опросник в визуальном стиле PAEI.

## Приватность

- ответы не отправляются на сервер;
- нет базы данных, cookies, localStorage или sessionStorage;
- нет групповой статистики;
- PDF формируется локально в браузере;
- Content Security Policy запрещает сетевые подключения приложения (`connect-src 'none'`).

## GitHub Pages

Загрузите все файлы из этой папки в корень репозитория. Затем откройте `Settings → Pages`, выберите `Deploy from a branch`, ветку `main` и папку `/(root)`.
